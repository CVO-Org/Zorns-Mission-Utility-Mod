# Zorn Mission Utility Mod

A collection of frameworks, tools and utilities for mission makers - originally built for our unit, cleaned up for public use.

> [!IMPORTANT]
> Some frameworks come with Eden modules, but most of the setup is done via config and SQF.
> Basic knowledge of Arma 3 config and SQF is required to get the most out of this mod.
> These addons were made to solve my own problems - happy to help with details, but basic SQF/config understanding is expected.

## Features
- [Role and SteamID based Arsenal Framework](../addons/arsenal/readme.md)
- [Custom Supply Crate Framework](../addons/csc/readme.md)
- [Loadout System (WIP)](../addons/loadout/readme.md)
- [Ambient Audio Framework](../addons/ambient/readme.md)
- [Diary System (WIP)](../addons/diary/readme.md)
- [Intel System (WIP)](../addons/intel/readme.md)
- [Unhide-Layer-Action](../addons/ula/readme.md)
- [Team Management](../addons/team/readme.md)
- [Fonts](../addons/fonts/readme.md)
- [Commonly used Functions](../addons/common/readme.md)

## Dependencies
