# Loadout
## Save Player Loadout and Restore it upon respawn

Saves a player loadout upon mission start and arsenal exit and applies it upon respawn.
![alt text](docs/img/loadout_saveRestore.png)

### Misc
- Creates ACE Arsenal Category for [GreenMag](https://steamcommunity.com/sharedfiles/filedetails/?id=2352603233) items when mod is loaded.
