# Team Management

Extends ACE's Team Management. Toggled via the CBA setting `Enable Team Management`.

## Features
- ACE Self-Interaction to become / step down as Teamleader of your fireteam color.
- 3DEN Attribute `Assign Fireteam Color` to set a unit's fireteam color at mission start.
- 3DEN Attribute `Teamleader` to make a unit the teamleader of its fireteam color at mission start.

## DUI
When [DUI - Squad Radar](https://steamcommunity.com/sharedfiles/filedetails/?id=1638341685) is loaded, the `team_dui` sub-addon additionally provides:
- Squadleader and Teamleader icons.
- Custom namelist sorting by fireteam, with leaders first.
